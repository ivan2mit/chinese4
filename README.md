# Банк иероглифов — декомпозиция

Статическая публикация страницы «Таблица декомпозиции» (`exercises/bank.html`)
из проекта `animcjk-task-editor`: 663 иероглифа YCT 1–4, разложенные на ключи,
с контурами черт и их порядком написания.

- `exercises/bank.html` — сама страница (открывается по пути сайта).
- `data/bank.json` — банк иероглифов; `data/extras.json` — ключи, радикалы и 38 базовых черт.
- `svgsZhHans/` — контуры иероглифов AnimCJK.
- `licenses/ANIMCJK-COPYING.txt` — лицензия AnimCJK, обязана лежать рядом с SVG.

Сборка: `npm run build:bank` в `animcjk-task-editor`, затем содержимое `bank-dist/`
копируется в этот репозиторий. Ручных правок здесь делать не нужно.
